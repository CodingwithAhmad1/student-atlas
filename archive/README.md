# Archive

Retired parts of Student Atlas, kept for reference only. Nothing here is built,
deployed, or imported by the live app (`frontend/`), the source monitor
(`monitoring/`), or the content MCP server (`mcp-content-server/`).

| Path | What it was |
| --- | --- |
| `app.py`, `models.py`, `requirements.txt`, `templates/`, `static/` | The original Flask app (Gemini chatbot, RSS news, server-rendered pages) |
| `CHANGES.md`, `SWE_GUIDE.md`, `student_atlas_nav_refactor.md` | Notes from the Flask era |
| `backend/` | SQLAlchemy models and session setup for a planned FastAPI backend that was never built |
| `supabase/` | Schema for the first source-monitoring design, before it moved to git-only state |
| `docs/PRODUCT_DOCUMENT.md` | Product document for the Flask-era app |
| `docs/StudentAtlas_UX_Redesign_Brief.md` | Brief for the React redesign (implemented) |
